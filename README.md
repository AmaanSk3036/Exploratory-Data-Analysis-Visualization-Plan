# Exploratory-Data-Analysis-Visualization-Plan
This report presents an exploratory data analysis (EDA) of the Online Retail dataset: 541,909 transaction line items recorded between 1 December 2010 and 9 December 2011. Using Python (pandas, NumPy, Matplotlib, Seaborn and Plotly), the analysis profiles the structure and quality of data, examines distributions ,outliers, and visualises patterns.
